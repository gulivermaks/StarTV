## Основні можливості

- **Чистий домашній екран без реклами:** жодних рекламних рядків, банерів і нав’язаних рекомендацій — лише ваші застосунки, вибрані стрічки та швидка навігація з пульта (`60 fps`).
- **ШІ-підбір фільмів і серіалів (Gemini + TMDB):** запити голосом або текстом, швидкі вечірні пресети (*«У компанії друзів»*, *«Сімейний вечір»*, *«Легке до 90 хв»*, *«Тримає в напрузі»*, *«На реальних подіях»*), точний пошук у TMDB, рейтинги TMDB / Кінопошуку / IMDb та запуск трейлерів.
- **Профілі глядачів і «Гостьовий вечір»:** до 4 локальних профілів (*Головний* + родинні, до 2000 записів у кожному), оцінки `1–10`, статуси (*Дивлюся зараз*, *Дивитися пізніше*, *Переглянуто*, *Подобається*, *Не цікавить*), нотатки прогресу (`S2 E4` / `01:15:00`), виключення небажаних жанрів та режим *«Гостьовий вечір»*.
- **Веб-пульт на телефоні (`http://<IP-ТВ>:8088`):**
  - хрестовина, гучність, відтворення, голосовий пошук і введення тексту з клавіатури телефона;
  - швидкий запуск застосунків ТВ, пошук та рекомендації ШІ, бібліотека з пошуком і сортуванням, пакетний імпорт CSV/TSV (до 1000 рядків), резервне копіювання JSON і діагностика приставки;
  - перемикання мови інтерфейсу пульта (`Як на ТВ / Українська / Російська / English`) і мови контенту (`uk / ru / en`).
- **Новини JW.ORG та JW Broadcasting:** окрема вкладка на ТВ і пошук у веб-пульті з відкриттям статей у легкому ТВ-браузері (`TV Bro`) та запуском трансляцій `tv.jw.org` / переглядача *JW Broadcasting* в один клік.
- **Гнучкий запуск плеєрів:** підтримка *Lampa* (включно з мостом ADB/CDP), *TorrServe*, *Stremio*, *NUM*, *HDRezka*, *Filmix*, *MEGOGO*, *VLC*, *Vimu*, *Kodi*, системного пошуку та браузера.
- **Синхронізація зі StarFilm:** двосторонній обмін бібліотекою, оцінками, профілями, виключеними жанрами та API-ключами через локальний Wi-Fi, а також запуск фільмів і трейлерів на ТВ прямо з мобільного застосунка [**StarFilm**](https://github.com/gulivermaks/StarFilm).
- **Погода, таймер сну та «Усі додатки»:** прогноз погоди (з авто-визначенням за часовим поясом або вибором міста в веб-пульті), налаштовувана полиця та верхні кнопки, таймер сну та безпечне повернення до заводського лаунчера в один клік.

## Встановлення та перший старт

1. Увімкніть на Android TV режим розробника та **Налагодження USB / по мережі** (порт `5555`).
2. Завантажте `StarTV.apk` зі сторінки [**Releases**](https://github.com/gulivermaks/StarTV/releases/latest) і встановіть через ADB:
   ```powershell
   adb connect <IP-ТВ>:5555
   adb install -r StarTV.apk
   ```
3. Запустіть **StarTV** на телевізорі (або в налаштуваннях виберіть *Головний екран → StarTV*).
4. Відкрийте **«Швидкий старт» (QR-код)** у *Підборі фільмів* або *Налаштуваннях* і відскануйте його телефоном, щоб:
   - відкрити веб-пульт у браузері або підключити мобільний застосунок **StarFilm**;
   - додати власні безкоштовні ключі **TMDB**, **Gemini** (опціонально) та **Kinopoisk Unofficial** (опціонально) і обрати ваше місто для погоди.
5. **Оновлення (OTA):** StarTV автоматично та за запитом (*Налаштування → Оновлення*) перевіряє нові релізи в `gulivermaks/StarTV` із перевіркою розміру, `SHA-256` та сертифіката підпису APK.

## Збірка та перевірка

Проєкт на чистому Android Java SDK (`minSdk 26`, `targetSdk 33`) без Gradle.

```powershell
# Повна перевірка (збірка APK, unit/http-тести, переклади, перевірка секретів, webOS/Tizen)
powershell -NoProfile -File tools/qa/check.ps1
```

Або в Git Bash / Linux / macOS:

```bash
./build.sh --generic
./tools/check.sh
```
